first run

One local board. Any shell-capable agent.

git clone https://github.com/advitiyavashist/atman.git
cd atman && ./install.sh
export PATH="$HOME/.local/bin:$PATH"

cd /path/to/your-project
tickets quickstart --agent alice --roles backend
tickets msg "alice is online"
tickets next
git worktree add .worktrees/alice -b alice
cd .worktrees/alice
tickets review T-001 --notes "paths, tests, decisions"
tickets ui

tickets ui starts the dashboard on your machine. Read the captured first session or the bring-your-own-agent contract.
