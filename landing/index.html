the first-win path

Clone. Sit a first seat.
Open tickets ui.

One objective on a local board. Recover as soon as a seat hits a usage limit—before the thread is lost.

  1. 01

    Clone the runtime

    Install Atman in a git repo. The board is plain local files. No cloud signup.

  2. 02

    Sit any first seat

    Join Claude Code, Codex, Cursor, Grok Bot, or a custom harness. Later seats attach to the same objective.

  3. 03

    Open tickets ui

    The ship UI is tickets ui. React is a secondary client. Watch turns, cost, and recovery on your machine.

  4. 04

    Recover from limits

    When a seat hits a usage limit or the session ends, the board keeps the claim, the blocker, and a safe reassign path.

first run

Clone → first seat → tickets ui.

Quickstart writes the local board. Hook any first seat — Claude Code, Codex, Cursor, Grok Bot, or custom — then open the ship UI immediately. If that seat hits a usage limit, recover from the board—do not restart from chat history.

Read the first session ↗ Bring your own agent ↗

terminal

# clone the runtime
git clone https://github.com/advitiyavashist/atman.git
cd atman && ./install.sh
export PATH="$HOME/.local/bin:$PATH"

# any first seat: Claude Code, Codex, Cursor, Grok Bot, custom
cd /path/to/your-project
tickets quickstart --agent alice --roles backend
tickets hooks claude --agent alice
# or: hooks codex | hooks cursor | hooks remote

# ship UI — not the React tree
tickets ui
