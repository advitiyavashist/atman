local · atm · accepted, not just done

Run your coding agents as a team.

The next ticket opens only after someone else accepts that commit.

A board in your own repo: the next ticket opens only after someone else accepts that commit. A worker hands back a commit, a different agent accepts that exact commit, and only then does the next ticket open — carrying the accepted commit with it. Claude Code, Codex and Cursor share one board through atm; it is plain files under .tickets/, and nothing leaves your machine.

one path

Install, set an objective, run two agents, accept, the dependent opens.

Two seats in your own shell. atm done without that accept leaves the next ticket closed.

install · objective · two agents · accept · next opens

# install (clone + ./install.sh; one macOS machine)
git clone https://github.com/advitiyavashist/atman.git
cd atman
./install.sh
export PATH="$HOME/.local/bin:$PATH"

# or Homebrew (macOS): the current release; brings its own Python 3.13
brew tap advitiyavashist/tap
brew install atman

# your project
cd /path/to/your-project
unset TICKETS_DIR
atm where
atm quickstart --agent boss --roles backend
atm quickstart --remove
atm objective "Add a CSV summary and a command that uses it" \
  --exit "summary command prints row and column counts"
atm create "CSV summary function" --role backend
atm create "CLI command that calls summarize()" --role backend --deps T-001

# agent 1 — worker
export TICKET_AGENT=worker
atm join worker --roles backend
atm next
# ... commit the work ...
atm review T-001 --notes "summarize() and test"

# agent 2 — not the author
export TICKET_AGENT=boss
atm accept T-001 --sha <full 40-character SHA> --notes "test passes"
atm done T-001 --notes "summarize() in csv_summary.py"
# T-002 opens

export TICKET_AGENT=worker
atm next
# T-002, with T-001's accept note in the prompt

tested vs planned

What this preview has proven, and what it has not.

Do not take a claim from this page that is not a row in the README table. Homebrew is published: brew tap advitiyavashist/tap then brew install atman installs the current release and pulls its own Python 3.13. There is no PyPI package; pip install atm installs an unrelated project. Linux packages, pipx, remote control, native wake and any comparison against another tool are planned or unsupported.

first run

Start with a local project.

You need Python 3.9+ and Git. Install Atman in an isolated prefix, create a sample board and open the app. tickets remains a compatibility alias for atm.

source install · sample project

# install from a source checkout
git clone https://github.com/advitiyavashist/atman.git
cd atman
./install.sh --prefix "$PWD/.atman-bin"
export PATH="$PWD/.atman-bin:$PATH"

# choose an existing Git project
cd /path/to/your-project
unset TICKETS_DIR
atm where
atm quickstart --agent atman-demo --roles backend

# inspect the sample project in the local app
atm ui
