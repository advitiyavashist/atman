# Support

Questions, bugs and documentation gaps go to
[GitHub issues](https://github.com/advitiyavashist/atman/issues).

Two things do not: a vulnerability or leaked credential goes through
[SECURITY.md](SECURITY.md), and a change you want to make goes through
[CONTRIBUTING.md](CONTRIBUTING.md) as a pull request.

Atman is a preview project maintained by one person. There is no support
portal, no rota and no response-time commitment.
