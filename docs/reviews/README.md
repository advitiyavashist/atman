# Review ledgers

These files are provenance for accepted public-surface work: exact SHAs,
repro commands, and the lines a review sent back. They are not the
first-read product path (`README.md`, `docs/first-session.md`).

Keep them in the public tree so an accept verdict can point at evidence
the README already links (for example `t819-readme-proof.md`). Operator
runbooks and unpublished prep stay under `docs/internal/`, which the
README does not link.

`docs/handoffs/` is the same kind of record for seat briefs and conflict
receipts.
